# [keegan.ch](https://keegan.ch)

My personal website.

## How to view and edit locally

- [install jekyll](https://jekyllrb.com/docs/installation/)
- run `jekyll serve`

## How to generate the CV pdf

- [install typst](https://github.com/typst/typst#installation)
- run `typst compile --root . cv/cv.typ docs/CV-Liam-Keegan.pdf`
